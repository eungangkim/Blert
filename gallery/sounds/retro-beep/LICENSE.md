# Retro beep — 출처와 라이선스

- **라이선스:** CC0 1.0 (Public Domain Dedication) — https://creativecommons.org/publicdomain/zero/1.0/
- **출처:** blert 작성자가 수식으로 직접 합성했습니다. 외부 음원, 샘플, 난수를 쓰지 않았습니다 (D-84).
- **만든 방법:** `gallery/tools/make_sounds.py`를 실행하면 같은 파일(같은 SHA-256)이 만들어집니다.
- **음색:** 사각파로 만든 짧은 8비트풍 삑 소리. 올라가는 3음(up), 내려가는 3음(down), 높은 두 음(account), 두 음을 번갈아 세 번(warn).
- **형식:** 모노, 22,050Hz, 16비트 PCM WAV. blert 소리 검사 기준(3초 이하, 512KB 이하) 안입니다.
- **확인 상태:** 파형과 blert 검증기 통과를 확인했고, 작성자가 직접 듣고 승인했습니다 (2026-10-13).
